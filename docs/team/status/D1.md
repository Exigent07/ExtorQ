    (host_service|application|k8s_workload|k8s_service), `category`, `adapter_support`,
    `monitoring_status` (as reported), `coverage` (effective:
    monitored|degraded|unmonitored|planned|unsupported), `include_removed`, `limit`, `offset`.
    `summary` = counts over the filtered scope before the coverage filter (stable chips).
  - `GET /api/v1/services/{service_id}` (`ServiceDetailResponse`): service record (endpoints with
    exposure + attribution), instances, telemetry per source (`collection` fresh|stale|
    no_collector_health + attributed event counts), `auth_activity`, `recent_events`, `findings`,
    `alerts` (whose `service_ids` contain it), `notes`; `since`/`until` window (default 24 h).
- Additive fields: `AssetDetailResponse.services_summary` + `child_assets` (Kubernetes nodes of a
  cluster); `OverviewResponse.service_coverage`; `AlertListItem/AlertRecord.service_ids`;

  k8s_pod_uid, k8s_container, k8s_container_id}`; `FindingItem.service_id`; `service_id` filter on
